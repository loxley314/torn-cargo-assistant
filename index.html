⬇️ Importar datos de la comunidad (TornW3B)

Su API está detrás de Cloudflare, así que no se puede leer desde la web. Abre weav3r.dev/travel-stock, en DevTools → Network busca history/batch, copia la respuesta y pégala aquí: la app guarda la cadencia de restock y la duración del stock de cada artículo.

🧳 Calculadora de capacidad (según el wiki)

¿Cómo se calcula?

Asumimos que el shop restockea «tiempo hasta el restock» después de quedarse a 0 (y, como el stock siempre vuela, el ciclo completo es restock + duración del stock). Para aterrizar justo en el restock:

salida = restock − duración del vuelo − margen

Ancla el cálculo justo cuando veas la tienda a 0: es el dato más preciso que existe (el primer restock queda clavado, sin la incertidumbre de cuánto ha durado el stock).

Comparar artículos del país

Coste real de cada artículo del país (YATA) contra tu precio de venta. Se ordena por beneficio por hueco de carga, que es lo que manda cuando la capacidad es limitada: no importa el artículo más caro, sino el que más rinde por hueco.

«Stock leído» viene de YATA y puede estar desfasado. Los precios de venta se guardan en este navegador, así que solo hay que teclearlos una vez.

Opcional · conectar con la API de Torn

La API de Torn no expone el stock de los shops abroad, así que el restock siempre hay que anclarlo a mano. Lo que sí puede hacer es leer tu vuelo actual (time_left) para decirte si vas a llegar a tiempo, y darte el valor de mercado de un artículo como precio de venta sugerido.

⚠️ La key viaja desde tu navegador directamente a api.torn.com y (si la marcas) se guarda en el localStorage de este sitio. No la uses en un PC compartido ni con una key de acceso completo.

Todas las horas son de tu reloj local. ⏱ Datos de stock y precios abroad: YATA (crowdsourced) · vuelo y precios: Torn API · cadencia de restock: TornW3B · capacidades: wiki de Torn.

Herramienta de fan sin relación con Torn City. Si mueves los parámetros (tiempo de vuelo, restock, duración del stock) el cálculo sigue valiendo para cualquier destino y artículo.
